## Technical writing sample

**Title:** Initial checkout process allowing continuation to the shipping stage with empty required fields

**Description:** When a user initiates their checkout process, the application allows them to continue to the "Shipping" stage with empty required fields.

**Steps to Reproduce:**

1. Go to URL: [https://xcelwetsuits.com/](https://xcelwetsuits.com/)
2. Choose from the navigation menu: Mens > Fullsuits
3. Click "View Product" on the first item that appears
4. Click "Add to Cart"
5. Click "Checkout" on the pop-up window
6. Input a test email, e.g., "test@gmail.com"
7. Click "Continue to Shipping"
8. Observe that the application allows the user to continue even though required fields are missing.

**Expected Result:**

Given a user has items in their cart and is located at the initial page of the checkout process after clicking the checkout button, they should be able to proceed to the shipping stage of the checkout process only when they have filled all the required fields.

The required fields are:

- Email
- First Name
- Last Name
- Address
- City
- State
- Zip Code

**Actual Result:**

Given a user has items in their cart and is located at the initial page of the checkout process after clicking the checkout button, the user is allowed to proceed to the shipping stage by only filling the email field and leaving the rest of the required fields empty.

**Priority:** 1

## How debug

I approach this systematically. I set aside two hours for myself in which I write down the issue, reproduction steps, expected result, and the series of attempts I can think of after debugging the code to find the source of the problem. If, after the set time, I haven't fixed the issue, I will reach out in the team channel with an outline of what I have documented, because at that point I am not being helpful to myself or the company. If I can't get guidance, I will pivot to another task and come back to this one later to at least make some progress.
