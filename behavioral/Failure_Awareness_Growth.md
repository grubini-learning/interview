## Completed feature twice at San Fernando

I was a manager for a React Native application that was created for the sales force of a poultry whole seller that registered orders made with small convenience stores. One of the features was completed twice and we ended we up scraping one of the implementations. I was so disappointed in myself. But in the end we are only human so I leveraged this into a learning opportunity to communicate better. One way I could’ve done this was by establishing a single source of truth and utilizing a ticketing system that would have identified to the team that the feature had already been assigned. Since then, I always make sure every team I work on has a system to ensure we are all on the same page and effectively communicating.

### Highlights

- humility
- growth mindset
- vulnerability
- learns from mistakes

## CollaborateMD - Asks process

I just had finished the onboard process in a full stack application and noticed there was a flaw in the work flow. This caused quite a lot of confusion on my end on how to proceed and ended having to reach out for help quite often. Because I am definitely one for efficiency, I developed a new process to not only achieve a quicker turnaround time, better communication within the team and show task prioritization. While I have tweaked this process throughout my tenure, I have found that it is still one I use quite successfully today.

    - set a goal
    - de scope
    - pick task
    - research
    - different attempts
    - times box it
    - times up

    - Thank people for their time
    - explain problem as granular as possible
    - what have you tried so far
    - what are a list of questions that can help you get unstuck
    - what are other possible solutions that you may have

    - If possible pair programming

### Highlights

- growth mindset
- awareness
- empathy
- plan oriented
- organized
- critical thinker

## Microsoft - Saw a fall out of sync problem after handing to engineering

Planning and estimating is a skill I have been polishing throughout my career. At Microsoft, I was presented with the opportunity to improve on this. I noticed that after design passed the specs to the engineering team, we would fall out of sync, causing missing the targeted time, decrease team synergy, obscure visibility to stakeholders, and a slight increase on the bugs found after initial implementation. In the implementation for our Auto Suggestions component, I decided to run a calculated test with the planning and implementation. I created meetings that included the needed stake holders within the execution phases in order to provide visibility and ensure that the progress was on track. In this case, it was the head designer in the acceptance criteria meetings I had created and to review his Figma file to provide live feedback when it came to areas like accessibility and complexity to maintain alignment. Through this experience, I was successful at creating an effective process that allows for more accurate estimations through more digestible and cohesive phases of work, increased overall visibility, decrease of bugs present in the end product, and increased synergy with team members.

### Highlights

- problem awareness
- proactive
- solution oriented
- collaboration
- communication
- resourceful
